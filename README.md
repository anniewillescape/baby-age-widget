# baby-age-widget

子どもの月齢をホーム画面に表示する iOS ウィジェットです。[Scriptable](https://scriptable.app/) 用のスクリプトとして動作します。

## 表示内容

- 名前と絵文字
- 現在の年齢・月齢（例: `3ヶ月 12日`、1歳以上は `1歳 2ヶ月 5日`）
- 週数（例: `15週3日`）と生後日数（例: `生後108日`）
- 次の月誕生日までの進捗バーと残り日数
- 月誕生日・誕生日当日はお祝いメッセージ（`🎉 今日で3ヶ月！` / `🎂 1歳のお誕生日！`）

表示は1日1回更新されます。

## 対応サイズ

| サイズ | レイアウト |
| --- | --- |
| Small | 月齢・週数・生後日数・進捗バーを縦に表示 |
| Medium | 左に月齢、右に「週数」「生後」のカード、下に進捗バー |

Small / Medium 以外のサイズでは Small のレイアウトで表示されます。

## インストール

1. iPhone / iPad に [Scriptable](https://apps.apple.com/app/scriptable/id1405459188) をインストールします。
2. Scriptable で新しいスクリプトを作成し、`baby-age-widget.js` の中身をすべて貼り付けて保存します。
3. ホーム画面に Scriptable のウィジェット（Small または Medium）を追加します。
4. ウィジェットを長押しして「ウィジェットを編集」を開き、以下を設定します。
   - **Script**: 手順 2 で保存したスクリプト
   - **Parameter**: 下記の形式で誕生日などを入力

## Parameter の書き方

カンマ区切りで指定します。誕生日以外は省略できます。

```text
誕生日,名前,絵文字,テーマ
```

| 項目 | 形式 | 省略時 |
| --- | --- | --- |
| 誕生日 | `YYYY-MM-DD`（必須） | — |
| 名前 | 任意の文字列 | `サンプル` |
| 絵文字 | 任意の絵文字 | `👶` |
| テーマ | 下記テーマ名 | `peach` |

例:

```text
2025-04-01,赤ちゃん,👶,peach
2024-11-20,はなちゃん,🌸,lavender
2025-02-14
```

### テーマ

| テーマ名 | 雰囲気 |
| --- | --- |
| `peach` | ピーチ系のやわらかいオレンジ |
| `mint` | ミントグリーン |
| `lavender` | ラベンダー |
| `sky` | 空色 |
| `night` | 濃紺のダークテーマ（進捗バーはゴールド） |

存在しないテーマ名を指定した場合は `peach` になります。

## うまく表示されないとき

- **「⚠️ Parameterを設定してください」と表示される**
  ウィジェットの Parameter が空です。上記の形式で誕生日を入力してください。
- **「⚠️ 誕生日の形式を確認してください」と表示される**
  誕生日が `YYYY-MM-DD` 形式になっていません（例: `2025-4-1` ではなく `2025-04-01`）。

いずれの場合もサンプルの誕生日（`2025-01-01`）で表示されます。

## プレビュー

Scriptable アプリ内でスクリプトを ▶ で実行すると、サンプルデータで Small サイズのプレビューが表示されます。
